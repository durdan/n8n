# Perplexity Research to Email Workflow

This workflow automates the process of conducting research using Perplexity AI and sending the results via email.

## Overview

The workflow consists of two main steps:
1. Research query using Perplexity API
2. Sending results via email

## Setup

### Prerequisites

- Perplexity API credentials
- Email sending configuration

### Configuration

1. Import the workflow JSON
2. Configure Perplexity API credentials
3. Set up email sending node with SMTP details

### Input Parameters

- researchTopic: Topic to research
- senderEmail: Email address to send from
- recipientEmail: Email address to send to

## Usage

1. Trigger the workflow with required parameters
2. Monitor execution in n8n dashboard
3. Check email for results

## Customization

- Modify email template
- Add additional processing steps
- Implement conditional logic

## Troubleshooting

- Verify API credentials
- Check email configuration
- Monitor execution logs
